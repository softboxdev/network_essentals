## Теоретическая часть (для самостоятельного изучения)

Ознакомьтесь со следующими методологиями и подходами:

1. **Waterfall** — каскадная модель, тестирование как отдельная фаза.
2. **V-модель** — соответствие этапов разработки и тестирования.
3. **Agile** (Scrum, Kanban) — итеративная разработка, непрерывное тестирование.
4. **TDD (Test-Driven Development)** — тесты пишутся до кода.
5. **BDD (Behavior-Driven Development)** — описание поведения на естественном языке (Gherkin).
6. **ATDD (Acceptance Test-Driven Development)** — приёмочные тесты до реализации.
7. **DevOps / CI-CD** — непрерывная интеграция и доставка, автоматизация тестов.
8. **Shift-Left / Shift-Right Testing** — смещение тестирования влево/вправо по циклу.
9. **Risk-Based Testing** — тестирование по рискам.
10. **Exploratory Testing** — исследовательское тестирование без заранее написанных сценариев.
11. **Пирамида тестирования** (М. Коэн) — unit → integration → UI.
12. **STLC (Software Testing Life Cycle)** — жизненный цикл тестирования.

**Рекомендуемые источники:**
- ISTQB Foundation Level Syllabus (русская версия).
- К. Канер, Дж. Бах, Э. Пэттон — «Тестирование программного обеспечения».
- С. Макконнелл — «Совершенный код» (главы про тестирование).
- Б. Хьюз, Л. Котник — «Путь тестировщика».
- Официальная документация Scrum Guide, Agile Manifesto.

### Шаг 4. Подготовка среды и запуск тестов (этапы 3–4 STLC) на примере https://example.com

```bash
#!/bin/bash
# run_stlc_tests.sh — выполнение тест-кейсов
WORKDIR="$HOME/stlc_homework"
LOG="$WORKDIR/04_execution/run_tests.log"
URL="${1:-https://example.com}"

PASS=0; FAIL=0

run_case() {
    local id="$1" name="$2" url="$3" expected="$4"
    code=$(curl -s -o /dev/null -w "%{http_code}" --max-time 5 "$url")
    if [ "$code" = "$expected" ]; then
        echo "[PASS] $id $name → $code" | tee -a "$LOG"
        ((PASS++))
    else
        echo "[FAIL] $id $name → $code (ожидалось $expected)" | tee -a "$LOG"
        ((FAIL++))
    fi
}

echo "=== STLC Test Run: $(date '+%F %T') ===" | tee -a "$LOG"
run_case "TC-01" "Доступность главной" "$URL" "200"
run_case "TC-02" "Обработка 404"        "$URL/not-found-xyz" "404"
run_case "TC-03" "robots.txt"           "$URL/robots.txt" "200"
run_case "TC-04" "favicon"              "$URL/favicon.ico" "200"
run_case "TC-05" "Проверка редиректа"   "$URL/" "200"

echo "Итого: PASS=$PASS FAIL=$FAIL" | tee -a "$LOG"
```
