# Практическая работа: Тестирование информационной системы в Linux (Bash)

**Тема:** Простейшее тестирование информационной системы с помощью bash-скриптов.

**Цель работы:** Научиться писать bash-скрипты для автоматической проверки работоспособности информационной системы: доступность сервисов, корректность ответов, целостность данных и логирование результатов.

**Оборудование и ПО:** ПК с ОС Linux (РОСА Линукс, Ubuntu, Fedora), терминал, установленный `curl`.

---

## Теоретическая справка

**Тестирование информационной системы (ИС)** — это проверка того, что система работает согласно требованиям: сервисы доступны, отвечают корректно, данные не повреждены, ошибок в логах нет.

Виды простейших проверок в bash:

| Тип проверки | Инструмент | Что проверяем |
|---|---|---|
| Доступность порта | `nc`, `curl`, `/dev/tcp` | Сервис слушает порт |
| HTTP-ответ | `curl -s -o /dev/null -w "%{http_code}"` | Код ответа 200/301/404 |
| Содержимое ответа | `curl` + `grep` | Наличие ключевого текста |
| Файлы и права | `test`, `ls`, `stat` | Наличие, права, размер |
| Процессы | `pgrep`, `ps` | Сервис запущен |
| Целостность данных | `md5sum`, `diff` | Файл не изменён |

**Коды возврата (exit codes)** — основа тестирования:
- `0` — тест пройден (успех);
- `1` — тест провален (ошибка);
- другие коды — специфические ошибки.

## Ход работы

### Шаг 1. Подготовка рабочей папки и тестовой «системы»

Создадим директорию для тестов и сымитируем простую информационную систему: файл данных и веб-сервер на Python.

```bash
mkdir -p ~/qa_test/{logs,data}
cd ~/qa_test

# Создаём "данные" ИС
echo "id,name,status" > data/users.csv
echo "1,Ivan,active" >> data/users.csv
echo "2,Petr,blocked" >> data/users.csv

# Запускаем простой HTTP-сервер на порту 8080 в фоне
python3 -m http.server 8080 --directory ~/qa_test/data &
echo $! > /tmp/qa_http.pid
```

Проверьте, что сервер отвечает:

```bash
curl -s http://localhost:8080/users.csv
```

### Шаг 2. Создание скрипта тестирования

Создайте файл `run_tests.sh`:

```bash
nano run_tests.sh
```

Введите код:

```bash
#!/bin/bash
# ==========================================
# Скрипт тестирования информационной системы
# ==========================================

LOG_FILE="$HOME/qa_test/logs/test_$(date +%Y-%m-%d_%H-%M-%S).log"
HOST="localhost"
PORT="8080"
URL="http://$HOST:$PORT/users.csv"

PASS=0
FAIL=0

# ---------- Функции ----------

log() {
    echo "[$(date '+%H:%M:%S')] $1" | tee -a "$LOG_FILE"
}

# Функция проверки: $1 — название теста, $2 — команда (должна вернуть 0)
check() {
    local name="$1"
    shift
    if "$@" >/dev/null 2>&1; then
        log "PASS: $name"
        PASS=$((PASS + 1))
    else
        log "FAIL: $name"
        FAIL=$((FAIL + 1))
    fi
}

# ---------- Начало ----------

log "===== Старт тестирования ИС ====="

# ТЕСТ 1. Сервер отвечает на порту 8080
check "HTTP-сервер доступен на порту $PORT" \
    bash -c "curl -s -o /dev/null --max-time 3 $URL"

# ТЕСТ 2. Код ответа = 200
check "HTTP-код ответа = 200" \
    bash -c "[ \"\$(curl -s -o /dev/null -w '%{http_code}' $URL)\" = '200' ]"

# ТЕСТ 3. В ответе есть заголовок CSV
check "Ответ содержит заголовок 'id,name,status'" \
    bash -c "curl -s $URL | grep -q 'id,name,status'"

# ТЕСТ 4. Файл данных существует и не пустой
check "Файл users.csv существует и не пуст" \
    test -s "$HOME/qa_test/data/users.csv"

# ТЕСТ 5. Количество строк в файле = 3 (заголовок + 2 записи)
check "Файл users.csv содержит 3 строки" \
    bash -c "[ \"\$(wc -l < $HOME/qa_test/data/users.csv)\" -eq 3 ]"

# ТЕСТ 6. Процесс http.server запущен
check "Процесс python3 http.server запущен" \
    pgrep -f "http.server 8080"

# ТЕСТ 7. Порт 8080 слушается
check "Порт $PORT слушается" \
    bash -c "timeout 2 bash -c '</dev/tcp/$HOST/$PORT'"

# ТЕСТ 8. Права на файл данных (чтение для всех)
check "Файл users.csv доступен для чтения" \
    test -r "$HOME/qa_test/data/users.csv"

# ТЕСТ 9. Проверка содержимого: есть пользователь Ivan
check "В данных есть запись 'Ivan'" \
    bash -c "curl -s $URL | grep -q 'Ivan'"

# ТЕСТ 10. Проверка отсутствия ошибок в ответе
check "Ответ не содержит слова 'error'" \
    bash -c "! curl -s $URL | grep -qi 'error'"

# ---------- Итог ----------

log "===== Результаты ====="
log "Пройдено: $PASS"
log "Провалено: $FAIL"
log "Лог сохранён: $LOG_FILE"

if [ "$FAIL" -eq 0 ]; then
    log "ИТОГ: Все тесты пройдены успешно!"
    exit 0
else
    log "ИТОГ: Есть проваленные тесты!"
    exit 1
fi
```

### Шаг 4. Проверка работы при сбое

Остановите сервер и запустите тесты снова — часть тестов должна провалиться:

```bash

./run_tests.sh
echo "Код возврата: $?"
```

**Ожидаемый результат:** тесты 1, 2, 3, 6, 7, 9, 10 провалятся, код возврата будет `1`. Это доказывает, что скрипт корректно обнаруживает неисправность ИС.
