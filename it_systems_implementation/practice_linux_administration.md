#  Практическая работа: Внедрение и поддержка компьютерных систем. Рабочее окружение ОС Линукс

**Цель работы:** Получить практические навыки создания, отладки и выполнения простых bash-скриптов в операционной системе Linux (на примере РОСА Линукс). Научиться автоматизировать рутинные задачи системного администратора.

**Оборудование и ПО:** ПК с установленной ОС РОСА Линукс (или любой Linux-дистрибутив с bash), терминал, текстовый редактор (nano, vim).

**Теоретическая справка:** BASH (Bourne Again SHell) — это командная оболочка, которая интерпретирует команды, вводимые пользователем. Скрипт — это текстовый файл, содержащий последовательность таких команд. Использование скриптов позволяет автоматизировать повторяющиеся действия, что является ключевым навыком для поддержки компьютерных систем.

##  Задание 1. Создание «Hello, World» скрипта и работа с правами доступа

**Цель:** Освоить базовый синтаксис, создание файла и управление правами на выполнение.

1. **Создайте рабочую директорию и перейдите в неё:**
   ```bash
   mkdir -p ~/scripts
   cd ~/scripts
   ```

2. **Создайте файл скрипта с помощью редактора nano:**
   ```bash
   nano hello.sh
   ```

3. **Введите следующий код:**
   ```bash
   #!/bin/bash
   # Это мой первый скрипт
   echo "Hello, ROSA Linux Administrator!"
   echo "Текущая дата: $(date)"
   ```

4. **Сохраните файл** (Ctrl+O, Enter) и выйдите (Ctrl+X).

5. **Попробуйте запустить скрипт стандартным способом:**
   ```bash
   hello.sh
   ```
   *Ожидаемый результат:* Ошибка `bash: hello.sh: команда не найдена` или `отказано в доступе`. Это связано с тем, что текущий каталог обычно не находится в переменной `$PATH`, а у файла нет прав на выполнение .

6. **Запустите скрипт через интерпретатор:**
   ```bash
   bash hello.sh
   ```
   *Результат:* Скрипт выполнится.

7. **Сделайте файл исполняемым и проверьте права:**
   ```bash
   chmod +x hello.sh
   ls -l hello.sh
   ```
   *Ожидаемый результат:* В строке прав появятся символы `x` (например, `-rwxr-xr-x`).

8. **Запустите скрипт как обычную программу:**
   ```bash
   ./hello.sh
   ```

## Задание 3. Автоматизация резервного копирования

**Цель:** Создать практический скрипт для поддержки компьютерных систем — резервное копирование директории с проверкой условий.

1. **Подготовьте тестовые данные:**
   ```bash
   mkdir -p ~/data/docs
   echo "Важный документ 1" > ~/data/docs/file1.txt
   echo "Важный документ 2" > ~/data/docs/file2.txt
   ```

2. **Создайте скрипт `backup.sh`:**
   ```bash
   nano backup.sh
   ```

3. **Введите код:**
   ```bash
   #!/bin/bash

   SOURCE_DIR="$HOME/data/docs"
   BACKUP_DIR="$HOME/backups"
   DATE_STAMP=$(date +%Y-%m-%d_%H-%M-%S)
   BACKUP_NAME="backup_$DATE_STAMP.tar.gz"

   # Проверка существования исходной директории
   if [ ! -d "$SOURCE_DIR" ]; then
       echo "Ошибка: Директория $SOURCE_DIR не найдена!" >&2
       exit 1
   fi

   # Создание директории для бэкапов, если её нет
   mkdir -p "$BACKUP_DIR"

   # Создание архива
   tar -czf "$BACKUP_DIR/$BACKUP_NAME" -C "$SOURCE_DIR" .

   # Проверка успешности создания архива
   if [ $? -eq 0 ]; then
       echo "Резервная копия успешно создана: $BACKUP_DIR/$BACKUP_NAME"
   else
       echo "Ошибка при создании резервной копии!" >&2
       exit 2
   fi
   ```

4. **Сделайте скрипт исполняемым и запустите:**
   ```bash
   chmod +x backup.sh
   ./backup.sh
   ```

5. **Проверьте результат:**
   ```bash
   ls -l ~/backups/
   ```
   *Результат:* Должен появиться архив `backup_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.tar.gz` .

## Задание 4. Обработка вывода команды и циклы

**Цель:** Научиться анализировать информацию о системе с помощью скрипта.

1. **Создайте скрипт `sysinfo.sh`:**
   ```bash
   nano sysinfo.sh
   ```

2. **Введите код:**
   ```bash
   #!/bin/bash

   echo "===== Информация о системе ====="
   echo "Имя хоста: $(hostname)"
   echo "Ядро: $(uname -r)"
   echo "Время работы: $(uptime -p)"
   echo ""

   echo "===== Использование диска (корень) ====="
   df -h / | tail -1
   echo ""

   echo "===== Содержимое домашнего каталога (файлы) ====="
   # Цикл по файлам в текущей директории
   COUNT=0
   for FILE in *; do
       if [ -f "$FILE" ]; then
           echo "Файл: $FILE (размер: $(stat -c%s "$FILE") байт)"
           COUNT=$((COUNT + 1))
       fi
   done
   echo "Всего файлов: $COUNT"
   ```

3. **Сделайте скрипт исполняемым:**
   ```bash
   chmod +x sysinfo.sh
   ```

4. **Запустите скрипт:**
   ```bash
   ./sysinfo.sh
   ```
   *Результат:* Скрипт выведет системную информацию и список файлов в текущей директории с их размерами .

## Задание 5. Условные операторы и проверка состояния системы

**Цель:** Научиться писать скрипты проверки, которые могут использоваться в мониторинге.

1. **Создайте скрипт `check_disk.sh`:**
   ```bash
   nano check_disk.sh
   ```

2. **Введите код:**
   ```bash
   #!/bin/bash

   THRESHOLD=80

   # Получаем процент использования корневого раздела
   USAGE=$(df / | tail -1 | awk '{print $5}' | sed 's/%//')

   echo "Текущее использование диска: ${USAGE}%"

   if [ "$USAGE" -ge "$THRESHOLD" ]; then
       echo "ВНИМАНИЕ: Использование диска превышает порог в ${THRESHOLD}%!" >&2
       exit 1
   else
       echo "OK: Использование диска в норме."
       exit 0
   fi
   ```

3. **Сделайте скрипт исполняемым:**
   ```bash
   chmod +x check_disk.sh
   ```

4. **Запустите скрипт и проверьте код возврата:**
   ```bash
   ./check_disk.sh
   echo "Код возврата: $?"
   ```
   *Результат:* Если использование диска меньше 80%, код возврата будет `0`, иначе — `1` .
