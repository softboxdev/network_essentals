## Что делать, если ничего не работает?

1. **Проверьте, что сервер запущен** в отдельном терминале.
2. **Проверьте порт:** если 8080 занят, используйте 8000 или 3000.
3. **Проверьте путь:** файлы должны быть в той же папке, где запущен сервер.
4. **Используйте `127.0.0.1` вместо `localhost`**, если не работает.

## Важные термины для запоминания

| Термин | Значение |
|--------|----------|
| **URL** | Адрес ресурса в интернете |
| **HTTP** | Протокол передачи гипертекста |
| **GET** | Метод запроса (данные в URL) |
| **POST** | Метод запроса (данные в теле) |
| **DNS** | Превращает домен в IP-адрес |
| **localhost** | Ссылка на свой компьютер |
| **Порт** | Номер "двери" для подключения |
| **Статус 200** | Всё хорошо |
| **Статус 404** | Страница не найдена |

## Теория (5 минут)

В интернете всё работает по принципу **«клиент-сервер»**:
1. **Клиент** (ваш браузер) отправляет **HTTP-запрос** на сервер.
2. **Сервер** обрабатывает запрос и отправляет **HTTP-ответ** (веб-страницу, картинку и т.д.).
3. **URL** (адрес) состоит из: `протокол://домен/путь`
   - Например: `http://example.com/index.html`
4. **DNS** превращает доменное имя (example.com) в IP-адрес.

Сегодня мы создадим свой мини-интернет на одном компьютере!

## Часть 2. Создаём локальный веб-сервер (20 минут)

В Linux есть простой встроенный сервер на PHP (если он установлен). Проверьте:

```bash
php -v
```

Если PHP не установлен, используем **Python 3** (он есть почти везде):
```bash
python3 -m http.server 8080
```

**Если Python не установлен вообще**, используем **netcat** (есть всегда):
```bash
# В одном терминале запускаем сервер
while true; do echo -e "HTTP/1.1 200 OK\n\nHello World" | nc -l -p 8080 -q 1; done
```

### Задание 2.1. Запускаем сервер

1. Откройте **первый терминал**.
2. Перейдите в домашнюю папку: `cd ~`
3. Запустите сервер:
   ```bash
   php -S localhost:8080
   ```
   или
   ```bash
   python3 -m http.server 8080
   ```

4. Увидите сообщение, что сервер запущен на порту 8080.

### Задание 2.2. Открываем страницу в браузере

1. Откройте браузер (Firefox/Chromium).
2. В адресной строке введите: `http://localhost:8080/index.html`
3. Вы увидите свою страницу!

**Вопрос в отчёт:** Что такое `localhost`? Почему мы можем открыть страницу без интернета?

## Часть 3. Эмуляция HTTP-запросов через терминал (20 минут)

В реальности браузер отправляет HTTP-запросы. Мы сделаем это вручную!

### Задание 3.1. Отправляем запрос с помощью curl

**Если curl установлен:**
```bash
curl -v http://localhost:8080/index.html
```

**Если curl нет, используем telnet или nc:**
```bash
telnet localhost 8080
```
Затем введите вручную:
```
GET /index.html HTTP/1.1
Host: localhost

```
(нажмите Enter дважды после Host)

### Задание 3.2. Анализируем ответ

**В выводе вы увидите:**

```
Connection: close

<!DOCTYPE html>
<html>
...
```

1. Какой статус ответа (200 OK)?
2. Что означает статус 404?
3. Какие ещё статусы вы знаете?
