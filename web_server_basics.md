## Что делать, если ничего не работает?

1. **Проверьте, что сервер запущен** в отдельном терминале.
2. **Проверьте порт:** если 8080 занят, используйте 8000 или 3000.
3. **Проверьте путь:** файлы должны быть в той же папке, где запущен сервер.
4. **Используйте `127.0.0.1` вместо `localhost`**, если не работает.

## Важные термины для запоминания

| Термин | Значение |
|--------|----------|
| **URL** | Адрес ресурса в интернете |
| **HTTP** | Протокол передачи гипертекста |
| **GET** | Метод запроса (данные в URL) |
| **POST** | Метод запроса (данные в теле) |
| **DNS** | Превращает домен в IP-адрес |
| **localhost** | Ссылка на свой компьютер |
| **Порт** | Номер "двери" для подключения |
| **Статус 200** | Всё хорошо |
| **Статус 404** | Страница не найдена |

## Теория (5 минут)

В интернете всё работает по принципу **«клиент-сервер»**:
1. **Клиент** (ваш браузер) отправляет **HTTP-запрос** на сервер.
2. **Сервер** обрабатывает запрос и отправляет **HTTP-ответ** (веб-страницу, картинку и т.д.).
3. **URL** (адрес) состоит из: `протокол://домен/путь`
   - Например: `http://example.com/index.html`
4. **DNS** превращает доменное имя (example.com) в IP-адрес.

Сегодня мы создадим свой мини-интернет на одном компьютере!

# Практическая работа: «Управление сетевыми портами в Linux. Освобождение занятых портов»

**Цель работы:** Научиться находить процессы, которые занимают сетевые порты, корректно завершать их и освобождать порты для новых приложений.

**Время выполнения:** 40-45 минут.

**Оборудование:** Компьютер с ОС Linux.

**Программное обеспечение:** Терминал, текстовый редактор.

---

## Теория (5 минут)

**Что такое порт?**
- Порт — это "дверь" в компьютер, через которую приложения общаются с сетью.
- Номера портов: от 0 до 65535.
- **Известные порты:** 80 (HTTP), 443 (HTTPS), 22 (SSH), 8080 (альтернативный HTTP).

**Почему порт может быть занят?**
- Приложение запущено и использует порт.
- Приложение завершилось некорректно (зависло).
- Другой процесс «завис» и не освободил порт.

**Что делать?**
1. Найти процесс по порту.
2. Определить, нужен ли он.
3. Корректно завершить процесс.

---

## Часть 1. Знакомство с портами (5 минут)

### Задание 1.1. Смотрим, какие порты сейчас открыты

Выполните команду:

```bash
sudo netstat -tulpn | grep LISTEN
```

**Разбор команды:**
- `netstat` — утилита для просмотра сетевых подключений
- `-t` — TCP порты
- `-u` — UDP порты
- `-l` — только слушающие (LISTEN) порты
- `-p` — показать PID и имя программы
- `-n` — показывать номера портов, а не имена

**Запишите в отчёт:**
- Какие порты сейчас открыты?
- Какие программы их используют?
- Какой порт использует ваш веб-сервер из предыдущей работы (если он запущен)?

### Задание 1.2. Альтернативная команда (если netstat нет)

Если `netstat` не работает, используйте:

```bash
sudo ss -tulpn | grep LISTEN
```

## Часть 3. Поиск процесса по порту (10 минут)

```bash

```


- Порт: 8080
- Процесс: `python3` с PID `12345`

**Способ 2. Через ss:**

```bash

```

**Способ 3. Через lsof (если установлен):**

## Часть 4. Освобождение порта (10 минут)

### Задание 4.1. Корректное завершение процесса

**Способ 1. Мягкое завершение (SIGTERM):**

```bash

```

Процесс получит сигнал на завершение и должен корректно закрыться.

**Способ 2. Принудительное завершение (SIGKILL):**

```bash
sudo kill -9 [PID]
```

Это «жесткое» завершение. Используйте, если процесс не реагирует на обычный `kill`.

### Задание 4.2. Проверяем, освободился ли порт

### Задание 4.3. Запускаем сервер снова

## Справочная информация

### Основные команды для работы с портами

| Команда | Назначение |
|---------|------------|
| `sudo netstat -tulpn` | Показать все открытые порты |
| `sudo ss -tulpn` | Альтернатива netstat |
| `sudo lsof -i :8080` | Показать процесс на порту 8080 |
| `sudo kill PID` | Завершить процесс |
| `sudo kill -9 PID` | Принудительно завершить процесс |
| `sudo pkill python3` | Завершить все процессы python3 |
| `sudo fuser -k 8080/tcp` | Убить процесс на порту 8080 |

### Стандартные порты для запоминания

| Порт | Сервис |
|------|--------|
| 22 | SSH (удалённое управление) |
| 80 | HTTP (веб-сервер) |
| 443 | HTTPS (безопасный веб) |
| 8080 | Альтернативный HTTP |
| 3306 | MySQL |
| 5432 | PostgreSQL |
| 27017 | MongoDB |

### Бонус: Использование fuser

**fuser** — утилита для поиска процессов по файлам и портам.

```bash
# Найти процесс на порту 8080
sudo fuser 8080/tcp

# Завершить процесс на порту 8080
sudo fuser -k 8080/tcp
```

**Задание:** Попробуйте завершить процесс на порту 8080 с помощью `fuser`.

**Вопрос:** Чем `fuser -k` отличается от `kill -9`?

## Типичные ошибки и их решение

| Ошибка | Решение |
|--------|---------|
| `netstat: command not found` | Установите net-tools: `sudo apt install net-tools` |
| `kill: (PID): No such process` | Процесс уже завершился, порт свободен |
| `Address already in use` | Порт занят, найдите и завершите процесс |
