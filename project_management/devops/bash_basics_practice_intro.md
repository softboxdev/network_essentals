## 📚 Часть 1. Знакомство с терминалом (15 минут)

### Что такое терминал?

**Терминал** — это окно, в котором можно давать компьютеру команды текстом, а не мышкой. Раньше все компьютеры работали только так. Сегодня терминал — главный инструмент программиста и системного администратора.

### Как открыть терминал

- В РОСА Линукс: меню «Пуск» → «Терминал».
- Или нажмите `Ctrl + Alt + T`.

Вы увидите приглашение командной строки, например:

```
student@pc:~$
```

Это значит: «пользователь `student`, компьютер `pc`, ты в домашней папке `~`, жду команду `$`».

### Первые команды — попробуйте сами!

Вводите команду и нажимайте **Enter** после каждой.

| Команда | Что делает |
|---|---|
| `whoami` | Показывает имя пользователя |
| `pwd` | Показывает, в какой папке вы находитесь |
| `ls` | Показывает список файлов в текущей папке |
| `date` | Показывает текущую дату и время |
| `echo Привет` | Печатает текст «Привет» |
| `clear` | Очищает экран |

**Задание 1.** Выполните все команды из таблицы. Запишите в тетрадь, что вывела каждая из них.

## 📁 Часть 2. Работа с папками (10 минут)

### Основные команды для папок

| Команда | Что делает |
|---|---|
| `mkdir имя` | Создать папку |
| `cd имя` | Перейти в папку |
| `cd ..` | Вернуться на одну папку вверх |
| `cd ~` | Вернуться в домашнюю папку |
| `rmdir имя` | Удалить **пустую** папку |

### Практика

Выполните по порядку:

```bash
cd ~                    # вернуться домой
mkdir bash_urok         # создать папку bash_urok
cd bash_urok            # войти в неё
pwd                     # проверить, где мы
```

## 📝 Часть 3. Создаём первый скрипт (20 минут)

### Что такое скрипт?

**Скрипт** — это текстовый файл, в котором записаны команды для терминала. Когда вы запускаете скрипт, компьютер выполняет все команды по порядку, как если бы вы вводили их вручную.

### Шаг 1. Создать файл

Мы используем редактор `nano` — он простой и есть везде.

```bash
cd ~/bash_urok          # убедимся, что мы в нужной папке
nano privet.sh          # создать файл privet.sh
```

Откроется пустое окно редактора.

### Шаг 2. Написать первую строку — «шапку»

В **первой строке** любого скрипта пишут:

```bash
#!/bin/bash
```

Эта строка называется **шебанг** (shebang). Она говорит компьютеру: «запускай этот файл через программу `/bin/bash`».

> ⚠️ Без неё скрипт может не запуститься.

### Шаг 3. Добавить команды

Допишите в файл:

```bash
#!/bin/bash
# Мой первый скрипт
echo "Привет, мир!"
echo "Сегодня: $(date)"
```

**Разбор:**
- `#` — начало комментария. Компьютер его игнорирует, а человек читает.
- `echo "..."` — команда «напечатай текст».
- `$(date)` — подставляет результат команды `date` внутрь текста.

### Шаг 4. Сохранить и выйти

В редакторе nano:
- `Ctrl + O` — сохранить.
- `Enter` — подтвердить имя файла.
- `Ctrl + X` — выйти.

### Шаг 5. Запустить скрипт — первый способ

```bash
bash privet.sh
```

**Результат:**
```
Привет, мир!
Сегодня: Пн сен 16 14:22:01 MSK 2024
```

### Шаг 6. Сделать скрипт «исполняемым» — второй способ

Сейчас файл — просто текст. Чтобы запускать его как программу, нужно дать ему **право на выполнение**:

```bash
chmod +x privet.sh
ls -l privet.sh
```

Вы увидите `-rwxr-xr-x` — появилась буква `x` (execute = выполнение).

Теперь можно запускать так:

```bash
./privet.sh
```

> ⚠️ Точка и слэш `./` в начале обязательны. Они означают «ищи файл в текущей папке». Без них Linux ищет программу в системных папках и не находит.

**Задание 3.** Создайте скрипт `info.sh`, который печатает:
- ваше имя,
- вашу школу,
- текущую дату.

Запустите его двумя способами: `bash info.sh` и `./info.sh`.

## 💬 Часть 4. Переменные и ввод с клавиатуры (20 минут)

### Что такое переменная?

**Переменная** — это «коробка» с именем, в которой хранится значение. Потом это значение можно использовать.

```bash
name="Иван"              # создать переменную (без пробелов вокруг =)
echo "Привет, $name"     # использовать её (знак $)
```

> ⚠️ Если написать `name = "Иван"` с пробелами — будет ошибка. Пробелы вокруг `=` недопустимы.

### Считывание ввода от пользователя

Команда `read` ждёт, пока пользователь введёт что-то и нажмёт Enter.

```bash
read -p "Как тебя зовут? " name
echo "Привет, $name!"
```

**`-p`** — «prompt», подсказка перед вводом.

### Скрипт «Знакомство»

Создайте файл `znakomstvo.sh`:

```bash
nano znakomstvo.sh
```

Введите код:

```bash
#!/bin/bash
# Скрипт знакомства

echo "Привет! Давай познакомимся."

read -p "Как тебя зовут? " name
read -p "Сколько тебе лет? " age
read -p "Какой твой любимый предмет? " subject

echo "-----------------------------"
echo "Тебя зовут: $name"
echo "Тебе лет: $age"
echo "Любимый предмет: $subject"
echo "Приятно познакомиться!"
```

Сохраните (`Ctrl+O`, Enter, `Ctrl+X`), сделайте исполняемым и запустите:

```bash
chmod +x znakomstvo.sh
./znakomstvo.sh
```

**Задание 4.** Измените скрипт: добавьте ещё один вопрос — «Какой твой любимый фильм?» — и выведите ответ.

## 🔀 Часть 5. Условие «если… иначе» (15 минут)

### Как работает if

```bash
if [ условие ]; then
    # выполнить, если условие истинно
else
    # выполнить, если ложно
fi
```

> ⚠️ Пробелы внутри `[ ... ]` обязательны! `[ $x -gt 5 ]` — правильно, `[$x-gt5]` — ошибка.

### Пример: проверка возраста

Создайте `vozrast.sh`:

```bash
#!/bin/bash
# Проверка возраста

read -p "Сколько тебе лет? " age

if [ "$age" -ge 18 ]; then
    echo "Ты совершеннолетний."
else
    echo "Ты ещё школьник."
fi
```

**Операторы сравнения чисел:**

| Оператор | Значение |
|---|---|
| `-eq` | равно |
| `-ne` | не равно |
| `-gt` | больше |
| `-lt` | меньше |
| `-ge` | больше или равно |
| `-le` | меньше или равно |

**Задание 5.** Напишите скрипт `ocenka.sh`, который:
- спрашивает оценку,
- если оценка `5` — печатает «Отлично!»,
- если `4` — «Хорошо»,
- иначе — «Надо подтянуть».

> 💡 Подсказка: используйте `if ... elif ... else ... fi`. `elif` — это «иначе если».

## 📝 Ответы на частые вопросы

**— Скрипт не запускается: «Permission denied».**
Сделайте `chmod +x file.sh` или запускайте через `bash file.sh`.

**— «command not found» при `./file.sh`.**
Проверьте, что вы в той же папке, где лежит файл: `ls`.

**— Ошибка «syntax error near unexpected token».**
Проверьте пробелы вокруг `[`, `]`, `=`, `then`. В bash они важны.

**— Русские буквы печатаются «кракозябрами».**
Проверьте кодировку терминала (должна быть UTF-8).

**— Как отредактировать скрипт?**
`nano file.sh` — снова откройте, измените, сохраните.
